# consoleExercises

Repositorio de ejemplos y ejercicios en .NET.

## Descripción
Colección de proyectos de consola y ejercicios que sirven para practicar características de .NET y patrones comunes. Contiene proyectos que apuntan a .NET 7 y .NET 9.

## Tecnologías
- .NET 7
- .NET 9
- Visual Studio 2022 (recomendado)

## Requisitos
- .NET SDK 7.0 y/o 9.0 instalado según el proyecto a usar: https://dotnet.microsoft.com/download
- Visual Studio 2022 con la carga de trabajo correspondiente
- Git

## Estructura del repositorio
Cada carpeta contiene un proyecto o ejercicio independiente. Ejemplo:
- `src/` - proyectos de aplicación
- `tests/` - proyectos de prueba (si existen)

(Ajusta la estructura según el contenido real del repositorio.)

## Compilar y ejecutar
Usando Visual Studio 2022:
1. Abrir la solución `.sln` en Visual Studio 2022.
2. Seleccionar el proyecto de inicio.
3. Ejecutar (F5 o Ctrl+F5).
